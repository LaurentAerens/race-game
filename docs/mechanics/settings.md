# Settings & Controls

All configurable options are stored in the game's settings and can be changed via the UI or configuration files.

## UI Scaling
- Press **F9** (or **Ctrl +** ) to increase UI scale for high‑DPI monitors.
- Press **F8** (or **Ctrl -**) to decrease scale.
- Press **F10** to reset to auto‑detected scale.

## Difficulty Levels
- **Easy**, **Normal**, **Hard**, **Expert** – affect AI aggressiveness, part wear rates, and pit stop times.

## Audio Settings
- Master volume, music volume, and SFX volume sliders appear in the Settings menu.

## Input Controls
- **Space** – Pause/Un‑pause the race.
- **1‑4** – Set simulation speed (1×, 2×, 4×, 8×).
- **C / Tab** – Toggle camera between overview and player‑car follow.
- **Esc** – Close the pit strategy modal.

These settings persist between sessions and are saved in `settings.json`.
